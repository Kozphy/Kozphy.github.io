# Freelance Offer Packaging Prompt

A reusable prompt for turning existing GitHub technical projects into clear, sellable freelance services. The original prompt and optional creator-led business extension are preserved verbatim below.

## Main prompt

```text
You are a freelance positioning strategist, B2B offer designer, and technical portfolio editor.

My goal is to turn my existing GitHub projects into clear, sellable freelance services.

Important:
- Do NOT tell me to build another large project unless absolutely necessary.
- Reuse my existing technical work as proof.
- Translate technical complexity into business value.
- Focus on offers that small businesses, startups, SaaS teams, AI teams, and engineering teams can understand and buy.
- Avoid vague phrases like "AI solutions", "digital transformation", or "full-stack development".
- Each offer must solve one specific painful problem.
- Prefer fixed-scope paid audits and paid pilots before large implementation projects.

My background:
- Accounting degree
- Python / C# / Golang / Rust
- Financial data processing
- CI/CD reliability
- AI evaluation
- AI governance
- Data validation
- Automation
- Audit / evidence-oriented workflows

My existing GitHub projects include:

1. Windows Network Recovery Toolkit
Capabilities:
- Proxy drift
- WinINET / WinHTTP
- TLS troubleshooting
- IPv4 / IPv6 failure diagnosis
- Browser-only failures
- Layered L1-L7 diagnosis
- Structured JSONL audit evidence
- Baseline / drift / remediation / verification
- Automated tests

2. CI Failure Orchestrator
Capabilities:
- Multi-repository CI failure analysis
- Failure classification
- Retry budgets
- Policy gates
- Human escalation
- SLO tracking
- Canary validation
- Audit evidence

3. EvalForge
Capabilities:
- LLM / AI-agent evaluation
- Golden datasets
- Evaluation runners
- Metrics
- LLM-as-Judge
- Human evaluation
- Baseline comparison
- Regression detection
- Policy gates

4. Financial / data projects
Capabilities:
- Python
- Excel / CSV processing
- Data validation
- Reconciliation
- Backtesting
- Risk controls
- Audit trails

Your task:

STEP 1 — Identify my 3 strongest freelance offers.

For each offer provide:
- Service name
- One-sentence customer problem
- Ideal customer
- What I deliver
- What is NOT included
- Delivery timeframe
- Entry price
- Paid pilot price
- Larger implementation price
- Why the customer would pay
- Which GitHub project proves I can do it

STEP 2 — Rewrite each offer in simple business English.

Use this format:

[Service Name]

I help [specific customer] solve [specific problem] by [specific method].

You receive:
- ...
- ...
- ...

Best for:
...

Starting at:
US$...

STEP 3 — Create a Contra service listing for each offer.

Include:
- Title
- Short description
- Full description
- Deliverables
- Process
- Timeline
- Price
- FAQ
- Call to action

STEP 4 — Create an Upwork Project Catalog version.

Include:
- Project title
- Search-friendly keywords
- Short summary
- Scope
- Deliverables
- Requirements from client
- 3 pricing tiers

STEP 5 — Turn each GitHub project into a client-facing case study.

Use:

Problem
What I found
What I built
Evidence
Business value
Who this is useful for
Call to action

Do NOT overfocus on architecture.

Explain why things like:
- retry budgets
- policy gates
- structured logs
- automated tests
- evaluation baselines

matter financially or operationally to a client.

STEP 6 — Create my personal positioning.

Give me:
- Contra headline
- Upwork title
- LinkedIn headline
- 2-sentence bio
- 100-word bio
- GitHub profile intro

My positioning should center on:

Reliability + AI Evaluation + Data Validation

NOT generic software engineering.

STEP 7 — Create a simple sales funnel.

Use:

Free technical content
↓
Low-risk audit
↓
Paid pilot
↓
Implementation
↓
Monthly support

Give one concrete example using my CI Failure Orchestrator.

STEP 8 — Tell me exactly what portfolio media I should create.

Limit it to:
- 3 portfolio cards
- 3 cover images
- 3 short demo videos
- 1 introduction video

For each, tell me exactly what should appear on screen.

STEP 9 — Critique my positioning.

Tell me:
- What is too technical
- What customers will not understand
- What sounds valuable
- What should be removed
- What should be emphasized

Do not flatter me.
Optimize for getting the first paying client.

Final goal:
I want a potential customer to understand within 10 seconds:
1. what problem I solve,
2. what they receive,
3. why they should trust me,
4. how much it costs,
5. how to hire me.
```

## Optional creator-led business extension

Append the following to the main prompt when using the creator-led one-person business approach:

```text
Think like a creator-led one-person business.

Do not sell my skills.
Package my expertise into simple products people can immediately understand and purchase.
```
